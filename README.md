# Dark Sounds

Локальный прототип мобильного ритм-боя. Два босса: Анна, Царица холодных баров (ANNA ASTI — «По барам») и Егор, последний холостяк Лотрика (Егор Крид — «Невеста»). HTML/CSS/JS без сборки и внешних пакетов.

## Локальный запуск

Из папки проекта: `python3 -m http.server 8000`, затем открыть [игру](http://127.0.0.1:8000/). Для ES-модулей и аудио нужен HTTP-сервер. Можно запустить `Start.command`.

Публичная версия: https://forallprime-debug.github.io/trackhero/. Для просмотра локальной версии на телефоне в одной Wi-Fi сети сервер запускают с `--bind 0.0.0.0` и открывают `http://<IP-компьютера>:8000`. Telegram Mini App требует опубликованного HTTPS-адреса.

## Экраны и настройки

Стартовый экран основан на Figma: портреты, рамки, стрелки, кнопка, ползунок и шрифт Angst находятся в `assets/`. Стрелки выбирают босса. Дополнительно размещён выбор одной из трёх раскладок: «Вокал / мелодия», «Ровный ритм», «Чередование дорожек». Можно выбрать первые 90 секунд или полный трек, задержку и тренировку без гибели. Рекорд хранится отдельно для каждого босса в этом браузере; старый рекорд Анны сохранён.

Музыка и карта загружаются заранее при выборе босса. Во время загрузки кнопка показывает прогресс; после готовности одно нажатие «В бой» запускает звук непосредственно из касания. При смене босса незавершённая загрузка отменяется. Карты готовятся заранее, телефон не анализирует аудио. AAC 128 кбит/с: Анна ~3,6 МБ, Егор ~3,2 МБ. Если AAC не поддерживается, загружается исходный MP3. Загрузка показывает прогресс и ограничена по времени; ошибки допускают повторную попытку.

После боя показывается общий Defeat или соответствующий боссу Victory. Экран результата остаётся до нажатия и возвращает к выбору боя. Никаких таймеров перехода нет. Локальный [просмотр экранов результатов](http://127.0.0.1:8000/tools/screens-preview.html) использует общий с игрой компонент и демонстрационные значения, без прохождения боя.

## Управление

Три дорожки: щит / пламя / меч. Касания или C / B / M; также поддерживаются стрелки влево / вниз / вправо. Нажимайте, когда центр ноты совпадает с золотой линией. Идеальное окно ±90 мс, точное ±180 мс, допустимое ±300 мс. Удерживайте длинные ноты. Обычное попадание даёт вспышку и искры, идеальное — золотой луч, кольцо и звёзды. Кнопка паузы и Escape останавливают музыку; уход из приложения тоже ставит бой на паузу.

Для победы нужно дойти до конца с минимум 85% попаданий. Качество влияет на очки, процент считается по количеству попавших нот; в результате округляется вниз. Промах отнимает 5 здоровья, обрыв удержания 3, пустое нажатие 1,5. Тренировка отключает гибель, но сохраняет порог победы. Положительная задержка смещает ноты позже относительно музыки.

Раскладки — автоматическая эвристика по музыкальному миксу. Вокал / мелодия оценивает высоту, периодичность и частотные атаки; это не разделение вокала и инструментов. Карты для обоих треков подготовлены заранее в `charts.json` и `charts-egor.json`. Для ручного уточнения музыкальных фраз понадобится дополнительная редактура.

## Проверки и подготовка карт

`npm test` (Node 22+) проверяет аудиозапуск, ошибки загрузки, тайминги, плотность карт, соответствие исходным записям, выбор босса и порог победы.

`node tools/build-charts.mjs <mono-float32-file> <sample-rate> [source-mp3] [output-json]` готовит все три раскладки из моно PCM Float32. Без последних двух аргументов используется трек Анны.

## Telegram и публикация

Встроены Telegram Web App SDK, безопасные отступы, полноэкранный режим, ориентация и пауза при деактивации. Обычный браузер работает самостоятельно. Реальную работу в Telegram на iPhone нужно проверять на устройстве после отдельной публикации.

Workflow `.github/workflows/pages.yml` публикует статические файлы только при отправке в `main` или ручном запуске. После разрешённой публикации HTTPS-адрес задаётся в @BotFather → `/mybots` → бот → Bot Settings → Configure Mini App / Menu Button. Токен бота фронтенду не нужен.

## Локальный Battle UI kit

`ui-kit.html` — рисованные карточки, соответствия магии и умений, состояния нажатия и попадания, интерактивная демонстрация отклика и палитра. PNG-атлас: `assets/battle/combat-atlas.png`; цвета и правила дорожек общие в `combat.js`.

В бою сверху летит магия босса: фиолетовую блокирует щит (C), синий лёд плавит пламя (B), зелёную отражает меч (M). Умения закреплены на золотой линии. Обычное попадание даёт короткий эффект умения, идеальное усиливает его золотым лучом и кольцом. Красная полоса игрока — здоровье, синяя — прогресс музыки, зелёная — серия попаданий. Порог победы и тайминги сохранены.


## Пять боссов (локальная версия)

Карусель идёт по кругу от 01/05 до 05/05. Источники MP3 находятся в `Music/` и соответствуют порядку префиксов 01–05. Основной режим — «Вариант 1 - Нормал» (classic); второй — «Вариант 2 - Изи» (pulse). Вокальная карта остаётся в данных для совместимости, но не предлагается в настройках.

| № | Босс | Трек | AAC 128 кбит/с | Карта |
|---|---|---|---|---|
| 01 | Анна | По барам | anna-playback.m4a | charts.json |
| 02 | Егор | Невеста | egor-playback.m4a | charts-egor.json |
| 03 | Принцы Пьяного Тумана | Малиновая Лада | princes-playback.m4a | charts-princes.json |
| 04 | Дочь базового минимума | Экспонат | mia-playback.m4a | charts-mia.json |
| 05 | Последний Наследник СДВГ | СДВГ | heir-playback.m4a | charts-heir.json |

Новые AAC содержат faststart для мобильной загрузки. Карты построены из соответствующих оригиналов; SHA-256 проверяется тестами. Длительность берётся из записи, а не из макета. Геометрия масок и слои портретов/фонов из Figma находятся в `boss-art.js`. Новые экраны победы используют портрет соответствующего босса в общей композиции результата.
