# Анна, Царица Холодных Баров

Мобильный ритм-бой, прототип 0.1. Статический HTML/CSS/JS, без сборки, API и зависимостей. Иллюстрация босса из предоставленного референса; MP3 из `Music/Anna_Asti_-_Po_baram.mp3`.

## Запуск

Из этой папки: `python3 -m http.server 8000`, затем открыть http://localhost:8000. Требуется HTTP-сервер (ES-модули и загрузка аудио не работают при открытии HTML через file://).

На телефоне: запустить сервер с `--bind 0.0.0.0` и открыть `http://<IP-компьютера>:8000` в той же Wi-Fi сети. Для Telegram нужен опубликованный HTTPS-адрес.

## Управление и правила

Три прямые дорожки без перспективы: щит / пламя / меч. Ноты и неподвижные кнопки используют изображения из `assets/01 Shield.png`, `assets/02 Flame.png`, `assets/03 Sword.png`. Три кнопки касанием; на компьютере C / B / M, также стрелки влево / вниз / вправо. Нажимать, когда центр крупной прямоугольной плитки совпадает с центром неподвижной мишени на золотой линии. Широкая полоса с тремя прямоугольными мишенями показывает место попадания; центр плитки должен совпасть с золотой линией. Узкая золотая полоса отмечает идеальное окно (±65 мс). Обычное попадание даёт короткую вспышку и немного искр; идеальное — золотой луч, расширяющееся кольцо и звёздные искры. После попадания показаны «раньше / позже» и величина отклонения в миллисекундах. Длинные ноты удерживать до конца хвоста. Поддерживаются одновременные касания. Пауза — кнопка вверху, Escape; при уходе из приложения игра автоматически останавливается. После продолжения есть 350 мс, чтобы снова зажать прерванное удержание.

Идеально: ±65 мс, точно: ±120 мс, допустимо: ±180 мс. Множитель растёт каждые 10 попаданий до ×4. Промах: −5 здоровья, раннее отпускание: −3, пустое нажатие: −1,5. Попадание восстанавливает немного здоровья. Тренировка отключает гибель. Для победы нужно дойти до конца и попасть минимум в 85% нот. Качество попадания влияет на очки, но не на условие победы; удержание даёт дополнительные очки. Процент в результате округляется вниз, чтобы 84,9% не отображались как победные 85%. Настройка смещения: положительное значение задерживает ноты относительно звука. При Bluetooth может требоваться ручная настройка.

Два режима: первые 90 секунд и полный трек. Новая раскладка «Ровный ритм» оценивает темп по частотным акцентам и строит равномерную сетку. На быстром треке используется каждая вторая доля, чтобы сохранить удобную плотность крупных плиток. Рисунок повторяется каждые восемь игровых долей: щит / меч с пламенем в конце фразы. В тишине нот нет. Зона попадания пульсирует по той же сетке; это подсказка доли, а не сигнал идеального попадания. Короткий и полный режимы имеют одинаковое начало. Первая раскладка доступна для сравнения. Это прототипная карта, не ручная транскрипция музыки. Вторая фаза пока меняет оформление. Босс — статический арт с реакциями на удары, не 3D-модель. Рекорд сохраняется локально на устройстве; серверного рейтинга нет.

## GitHub Pages

1. Загрузить проект в нужный GitHub-репозиторий, ветка `main`.
2. Settings → Pages → Source → GitHub Actions.
3. Workflow `.github/workflows/pages.yml` проверит тайминги и опубликует только файлы игры, `assets/` и `Music/`.
4. Адрес будет `https://<user>.github.io/<repo>/`. Все пути относительные и поддерживают размещение в подпапке.

## Telegram Mini App

Встроен официальный Telegram Web App SDK: ready/expand, безопасные отступы, полноэкранный режим и блокировка ориентации на поддерживаемых версиях, пауза при деактивации. В обычном браузере игра работает независимо от Telegram.

После публикации задать HTTPS URL в @BotFather: `/mybots` → нужный бот → Bot Settings → Configure Mini App (или Menu Button). Токен бота не нужен фронтенду и не должен попадать в репозиторий. Авторизации и серверных результатов в этой версии нет.

Документация SDK: https://core.telegram.org/bots/webapps

## Проверки

`node --test tools/rhythm.test.js` — окна попаданий, поиск ближайшей ноты, множитель, детерминированность и интервалы карты. Node 22+; npm-пакеты не нужны.


### Третий вариант: вокал / мелодия (эксперимент)

Отдельный режим `vocal`, выбран по умолчанию. Оценивает периодичность сигнала, высоту и соотношение частотных полос. В предположительно вокальных секциях ищет слоговые среднечастотные атаки, в остальных — мелодические акценты более широкого диапазона. Высота задаёт дорожку; близкие повторения разводятся по соседним дорожкам. Протяжённая стабильная высота становится удержанием. Минимальный интервал 320 мс, повтор одной дорожки — 650 мс, не более 9 нот в скользящем окне 4 с.

Это эвристика по готовому миксу, не разделение голоса и инструментов: синтезатор может быть принят за голос. Для точной вокальной карты нужна отдельная вокальная дорожка или ручная правка. Первые два варианта сохранены.
